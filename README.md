# Termlet frontend

A static copy of the [original student sublet demo](https://termlet-demo.netlify.app/) with fictional listings and simulated payments.

Open `site/index.html` locally, or run `python3 -m http.server 8000 --directory site` and visit http://localhost:8000.

## Iterations

Start each iteration on a new branch from the previous iteration, using a name such as `iteration/002-search`. Keep public files in `site/`. Commit and push the branch. GitHub Actions publishes every numbered iteration to its own URL and the highest-numbered iteration at the site root. Keep published iteration branches so their previews remain available.
